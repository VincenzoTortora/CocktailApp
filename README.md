# CocktailApp - Digital Mixology & Bar Management

Un'applicazione Android nativa progettata per digitalizzare l'esperienza all'interno del bar, ottimizzare la gestione delle ricette e supportare la creazione di cocktail interattivi e d'avanguardia.

## 🍹 Funzionalità Principali (o Roadmap di Sviluppo)

* **Ricettario Digitale Avanzato:** Archiviazione e consultazione rapida delle ricette dei cocktail, con bilanciamento automatico delle once (oz) e dei millilitri (ml).
* **Gestione Esperienze Interattive:** Sezione dedicata all'ideazione di drink innovativi, inclusi dettagli di servizio complessi (es. calcolo e tempistiche per preparazioni speciali come mousse topper, velluti o guarnizioni interattive).
* **Calcolo del Drink Cost:** Strumento integrato per determinare il costo vivo di ogni singolo cocktail basandosi sul prezzo delle materie prime in inventario.

## 🛠️ Stack Tecnico

* **Linguaggio:** Kotlin / Java
* **Ambiente di Sviluppo:** Android Studio
* **Persistenza Dati:** Progettazione del database locale per la memorizzazione di ingredienti, ricette e menu dinamici.
